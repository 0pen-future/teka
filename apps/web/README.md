# Teka Web

React front end for Teka: Vite + React 19 + TypeScript (strict), Tailwind CSS v4
with shadcn/ui, React Router v7, TanStack Query, and Zustand.

## Development

```bash
npm install
npm run dev        # http://localhost:5173 (or `make web-dev` from the repo root)
```

The dev server reads `.env.development` (`VITE_API_URL`, pointing at the Go API
on localhost:8080). `VITE_*` variables are embedded in the client bundle and are
public by design — never put secrets in them. Production builds must supply
`VITE_API_URL` at build time or the app refuses to start with a config error.

## Scripts

| Command                | Purpose                                    |
| ---------------------- | ------------------------------------------ |
| `npm run dev`          | Dev server with HMR                        |
| `npm run build`        | Typecheck + production bundle to `dist/`   |
| `npm run lint`         | ESLint (flat config, type-aware)           |
| `npm run format`       | Prettier write                             |
| `npm run format:check` | Prettier verify                            |
| `npm run typecheck`    | `tsc -b --noEmit`                          |
| `npm run test`         | Vitest unit/component suite (offline, MSW) |
| `npm run test:watch`   | Vitest in watch mode                       |
| `npm run e2e`          | Playwright e2e (needs running dev stack)   |
| `npm run preview`      | Serve the production build locally         |

## Structure

Feature-module layout (`src/app`, `src/features/*`, `src/components`,
`src/layouts`, `src/lib`, `src/styles`) — the contract, state-management split,
and API error handling are documented in
[`docs/frontend-guidelines.md`](../../docs/frontend-guidelines.md).
`src/components/ui/` is generated by the shadcn CLI; regenerate instead of
hand-editing.
