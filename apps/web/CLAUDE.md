# apps/web — React front end

Vite + React 19 + TypeScript (strict), Tailwind CSS v4, React Router,
TanStack Query, Zustand. Scripts and env setup: `README.md` in this folder.

## Structure

- `src/features/<domain>/` — feature modules with `api/`, `components/`,
  `hooks/`, `pages/`, `schemas/`, `routes.tsx`, and colocated `__tests__/`.
  New UI belongs in a feature module, wired through `src/app/router.tsx`.
- `src/components/hv/` — the in-house design system (hv-button, hv-card,
  hv-modal, status-pill, …). Prefer these over raw shadcn or new one-off
  components.
- `src/lib/api/` — API access layer (`client.ts`, `envelope.ts`, `errors.ts`,
  `interceptors.ts`, `public-client.ts`). Feature `api/` files go through this
  layer, never raw axios/fetch.

## Constraints

- MUST NOT hand-edit `src/components/ui/` — generated by the shadcn CLI;
  regenerate instead.
- MUST NOT put secrets in `VITE_*` variables — they are embedded in the public
  client bundle.

## Verification

- `npm run typecheck` and `npm run test` (Vitest + MSW, fully offline).
- `npm run e2e` (Playwright) needs the running dev stack; the isolated e2e
  stack uses compose project `teka-e2e` with port/URL overrides.

## Pointers

- Conventions (module contract, server/client state split, API error handling,
